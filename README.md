# Scale Up

A game for learning system design by breaking things.

You run a startup in a neon city. Traffic keeps growing, your architecture
keeps failing, and every fix teaches you one real concept: load balancing,
caching, replication, queues and more. Built for people prepping for
system design interviews who find reading about it hard to stick.

## Status

Early stage. Right now this repo is the landing page. The game itself
(the simulation engine and the playable levels) is next.

## Run it locally

    npm install
    npm run dev

## Stack

React, TypeScript and Vite.
